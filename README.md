# Invitación Mariana & Sebastián

Demo comercial premium, responsive y sin instalación. Abre `index.html` para verla.

## Cambiar la pareja

Edita únicamente `config.js`: nombres, monograma, fecha, lugar destacado, textos, historia, sedes, itinerario, código de vestimenta, regalos, fecha límite de RSVP, WhatsApp e imágenes. El diseño vive en `styles.css` y las interacciones en `app.js`.

Las fotografías incluidas son ficticias y están dentro de `assets/images`. Para otra pareja, sustituye esos archivos o cambia sus rutas en `config.js`.

## Formularios

En esta demo, el RSVP se guarda localmente en el navegador. Para un cliente real, conecta el envío a Formspree, Netlify Forms, Google Sheets o Supabase.

## Vista previa

Puedes abrir `index.html` directamente. Para una prueba idéntica a la publicación, sirve la carpeta con cualquier servidor estático local.

## Publicación gratuita

GitHub Pages: sube el contenido de esta carpeta a un repositorio, abre Settings → Pages, elige la rama principal y la carpeta raíz. La web quedará disponible en la dirección que GitHub muestre.

También funciona sin cambios en Cloudflare Pages, Netlify o cualquier alojamiento estático.
